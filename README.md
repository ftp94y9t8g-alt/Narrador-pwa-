# Narrador

Prototipo PWA móvil para convertir PDFs con texto seleccionable en una experiencia de audiolibro.

- Importación local de PDF
- Detección básica de capítulos
- Biblioteca guardada en el dispositivo
- Narración con las voces disponibles en iOS / navegador
- Instalación como PWA

El objetivo de esta fase es mantener el desarrollo en $0. La capa de voz está separada para poder sustituirla más adelante por un motor más natural sin rehacer la app.
